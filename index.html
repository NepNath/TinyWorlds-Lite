v0.2.4 - about this build

this is a really early version of the game, that's why its not pretty nor complete

for now : only the following elements are available :

  • void : the base resource, that can be gathered and then converted for "raw materials".
  • raw materials : the base resources, that will later be used to make buildings for autofarming, houses and upgrades.
  • save system : a basic save system that allows you to save your progress, all you have to do is to generate a save code, and keep it somewhere.
  • very basic display :The display you see right now is very basic and temporary.
